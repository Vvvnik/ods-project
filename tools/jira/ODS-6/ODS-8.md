## Описание

Реализовать Java-классы контроллеров, которые обрабатывают HTTP-запросы согласно контрактам из Задачи 1, и слой доступа к данным для взаимодействия с PostgreSQL.

### Требования:

Контроллеры (@RestController):

	
- Создать класс UserController с методами для каждого эндпоинта из спецификации.
	
- Методы должны принимать и возвращать DTO-объекты (UserRequest, UserResponse).
	
- Обрабатывать исключения и возвращать соответствующие HTTP-статусы.

Слой доступа к данным (DAO/Repository):

	
- Создать интерфейс UserRepository (например, на основе Spring Data JPA).
	
- Реализовать методы: save(), findById(), findAll() с пагинацией, deleteById().
	
- Обеспечить уникальность поля email на уровне БД (уникальный индекс).

Модели данных:

	
- Создать JPA-сущность UserEntity с маппингом на таблицу users.
	
- Поля: id, name, email, createdAt, updatedAt.

Конфигурация БД:

	
- Настроить подключение к PostgreSQL через application.yml.
	
- Использовать Flyway или Liquibase для миграции БД (создать скрипт создания таблицы users).

### Критерии приемки:

	
- Эндпоинты из спецификации реализованы и отвечают на запросы.
	
- Данные сохраняются и извлекаются из PostgreSQL.
	
- При попытке создать пользователя с существующим email возвращается 409 Conflict.
	
- Пагинация для списка пользователей работает корректно.
