=== Релиз-описание изменений

Разработан Сервис управления пользователями на стеке Spring Boot с PostgreSQL и Swagger-документацией. Реализован REST API для CRUD-операций над сущностью «Пользователь» с эндпоинтами: POST /api/v1/users (создание), GET /api/v1/users (список с пагинацией и фильтрацией по email), GET /api/v1/users/{id} (получение по ID), PUT /api/v1/users/{id} (обновление), DELETE /api/v1/users/{id} (удаление). Модель данных содержит поля id (UUID), name (required, минимальная длина 2 символа), email (required, unique, формат email), createdAt и updatedAt. == ODS-10

//tag::ODS-10[]
=== Исправление обработки пагинации в эндпоинте GET /api/v1/users 

Исправлена ошибка в работе эндпоинта управления пользователями, который ранее игнорировал параметры пагинации или возвращал полный список данных без учёта page и size параметров. В реализации применены стандартные механизмы пагинации Spring Data JPA для корректного разделения запроса по страницам. Добавлена валидация входных параметров: проверка, что page не менее нуля, а size находится в диапазоне от 1 до 100, при нарушении возвращаются сообщения об ошибке с кодом 400 Bad Request. Эндпоинт теперь возвращает JSON‑структуру с полями content, totalPages, totalElements, size, number, first, last. Развёрнута поддержка параметров по умолчанию: page=0 и size=20 при отсутствии явного указания. Написаны unit‑тесты для проверки различных комбинаций параметров и интеграционные тесты через Swagger UI и Postman для подтверждения корректной работы функционала пагинации.
//end::ODS-10[]
