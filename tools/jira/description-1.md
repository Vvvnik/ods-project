## ODS-6

### Разработать Сервис управления пользователями

<!-- //tag::ODS-6[] -->
В данном релизе реализован сервис управления пользователями, включающий полностью спроектированную спецификацию REST‑API в формате OpenAPI, а также контроллеры и репозиторий, взаимодействующие с PostgreSQL. Сервис поддерживает CRUD‑операции, пагинацию, поиск по части email и сортировку списка, а также содержит валидацию email и имени согласно стандартам JSR‑380. На уровне базы данных гарантирована уникальность email благодаря индексу и миграции через Flyway. Добавлены аудиты действий в таблицу user_audit, что обеспечивает трассируемость создания, обновления и удаления пользователей. Все эндпоинты автоматически документируются в Swagger UI по адресу /swagger‑ui.html, обеспечивая интерактивный доступ к описанию и примерам запросов.

## ODS-10

### Исправить ошибку обработки пагинации в эндпоинте GET /api/v1/users сервиса управления пользователями

<!-- //tag::ODS-10[] -->
В релизе исправлена ошибка пагинации в эндпоинте GET /api/v1/users: теперь параметры page и size корректно передаются в слой данных, а возвращаемый JSON соответствует ожидаемой структуре с полями content, totalPages, totalElements, size, number, first и last. Добавлена валидация входных параметров – запрос с page < 0 или size > 100 приводит к статусу 400 Bad Request с точными сообщениями об ошибке, а при отсутствии параметров используется page = 0 и size = 20. Логика метода UserController.getUsers пересмотрена для использования Pageable и Page, обеспечивая корректную пагинацию даже на последних и несуществующих страницах. В проекте задокументированы unit‑тесты, проверяющие работу с различными комбинациями параметров, структуру ответа и обработку крайних случаев, а также интеграционные тесты через Swagger UI подтвердили правильность реализации. Все тесты проходят успешно, а клиенты теперь могут безопасно запрашивать списки пользователей постранично.
<!-- //end::ODS-10[] -->
