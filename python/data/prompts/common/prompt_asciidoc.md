# Формат AsciiDoc (универсально)

Склейка промпта: **intro → формат (этот файл) → develop** (содержание и структура тела — **только** в последнем develop-файле из конфига).

## Обязательный префикс фрагмента

1. Строка 1: `=== <краткий заголовок>` (ориентир до ~10 слов). Заголовков `==` **нет**.
2. Строка 2: пустая.
3. Далее **тело** — как задаёт **develop**: число абзацев, объём, нужен ли список.

## Запреты

- Markdown: `#`, `##`, fenced code blocks (тройные обратные кавычки), подсветка языка в блоках.
- Оформление жирным/курсивом через `*` вокруг фраз (не путать с маркерами списка в начале строки).
- Текст до первой строки `===` или после фрагмента; служебные вступления.
- Символы вне латиницы/кириллицы (кроме обычной пунктуации).

## Списки (если develop требует)

- Перед списком — вводная строка, заканчивающаяся на `:`; затем пустая строка; затем `*` / `**` или `.` / `..` — без смешения нумерации и `*` в одной ветке и без пропуска уровней.
- Пункты как законченные предложения: между ними `;`, после последнего `.`.
- Пустая строка между абзацем и списком и после списка перед следующим текстом.

## Типографика

- Элементы UI — в кавычках «ёлочки».

## Self-check

1. Первая строка — `===`, вторая пустая; тело и списки — по **develop**; синтаксис списков — по этому файлу, если список есть.
2. Нет Markdown и нет `==`.
