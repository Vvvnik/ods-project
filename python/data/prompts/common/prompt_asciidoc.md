# Формат AsciiDoc (каркас фрагмента)

Используется в **legacy**-склейке промпта: intro → этот файл → develop (`generate_description.py`).

Для контура **Hermes** детальные правила разметки задаются skills в `~/.hermes/skills/` (в первую очередь **`my/asciidoc`** и **`my/description_writer`**), а не этим файлом — чтобы не было двух расходящихся источников правил.

## Обязательный префикс фрагмента

1. Строка 1: `=== <краткий заголовок>` (ориентир до ~10 слов). Заголовков `==` нет.
2. Строка 2: пустая.
3. Далее тело — как задаёт **develop**: объём, абзацы, списки.

## Минимальные запреты

- Markdown: `#`, `##`, fenced code blocks (тройные обратные кавычки).
- Текст до первой строки `===` или после фрагмента; служебные вступления.
- Символы вне латиницы/кириллицы (кроме обычной пунктуации).

Списки, пустые строки, `**`, backticks — см. skill **`my/asciidoc`** (Hermes).

## Self-check

1. Первая строка — `===`, вторая пустая; тело — по develop.
2. Нет Markdown-заголовков `#` и нет `==`.
