== Общие положения

Данный документ содержит описание программы информационной системы управления предприятием в соответствии с требованиями ГОСТ 19.101-77 "ЕСПД. Виды программ и программных документов".

Документ предназначен для:

* Программистов-разработчиков системы;
* Системных администраторов;
* Технических специалистов.

== Общие сведения о программе

=== Наименование программы

Полное наименование программы: "Информационная система управления предприятием".

Сокращенное наименование: "ИСУП".

Идентификатор программы: ISP-V.1.0.

=== Назначение программы

Программа предназначена для автоматизации основных бизнес-процессов предприятия:

* Управление финансами;
* Кадровый учет;
* Управление запасами;
* Формирование отчетности.

=== Условия применения программы

Программа работает в следующих условиях:

* Операционная среда: Windows Server, Linux;
* База данных: PostgreSQL;
* Веб-интерфейс: современные браузеры.

== Техническое назначение

=== Функциональное назначение

Программа обеспечивает автоматизацию управления предприятием:

* Ведение справочников основных данных;
* Обработка документов учета;
* Формирование управленческих отчетов;
* Контроль исполнения бизнес-процессов.

== Техническая реализация

=== Системные требования

. Требования к серверной части:
.. Операционная система: Windows Server 2019 или Linux CentOS 8;
.. Память: минимум 8 GB RAM;
.. Дисковое пространство: минимум 100 GB;
.. Процессор: Intel Xeon или аналог.

. Требования к клиентской части:
.. Веб-браузер: Chrome 90+, Firefox 88+, Safari 14+;
.. Разрешение экрана: минимум 1024x768;
.. Подключение к локальной сети предприятия.

=== Архитектура программы

Программа построена по архитектуре клиент-сервер:

* Веб-клиент обеспечивает пользовательский интерфейс;
* Серверное приложение обрабатывает бизнес-логику;
* База данных хранит все учетные данные;
* Веб-сервер обеспечивает взаимодействие компонентов.

== Заключение

Программа обеспечивает комплексную автоматизацию управления предприятием и готова к промышленной эксплуатации.

Поддержка программы включает техническую документацию, консультирование по установке и настройке, а также техническую поддержку в течение гарантийного периода.
