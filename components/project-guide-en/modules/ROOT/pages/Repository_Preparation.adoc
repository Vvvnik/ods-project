== Repository Root Documents

Important documents describing the project and rules for working with it are located in the project root:

[cols="1,2,3", options="header, breakable"]
|===
^|File ^|Purpose ^|Description

|README.md
|Main Project File
|ODS description, quick start, license links

|readme.adoc
|Alternative README
|Project description in AsciiDoc format

|MANIFESTO.adoc
|Project Manifest
|Principles, applications, ODS profile ecosystem

|NOTICE.adoc
|Third-party Software Notice
|List of used libraries and their licenses

|LICENSE.md
|Summary License
|Explanation of the project's dual licensing model

|LICENSE-CODE.md
|Code License
|Apache 2.0 for code, scripts, tools

|LICENSE-DOCS.md
|Documentation License
|CC-BY 4.0 for documentation, templates, texts

|package.json
|Node.js Dependencies
|Description of dependencies and scripts

|package-lock.json
|Exact Dependency Versions
|Reproducible builds

|antora-playbook.yml
|Antora Configuration
|Documentation site build settings

|CONTRIBUTING.md
|Contribution Guide
|Participation rules, project structure, documentation work

|CODE_OF_CONDUCT.md
|Code of Conduct
|Standards of behavior for project participants

|SUPPORT.md
|Project Support
|Where to find help, FAQ, contacts

|SECURITY.md
|Security Policy
|Vulnerability reporting procedures

|CHANGELOG.md
|Change History
|Change log following Keep a Changelog standard
|===

For detailed description of all root documents, see xref:Project_Root_Documents.adoc[Project Root Documents].
