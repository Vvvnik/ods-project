= Docker Build and Services

== Images

* **Universal Image**: registry.gitlab.com/vvvnik/ods-project/ruby-node-antora:2:
** Contains Ruby 3.2 + Node.js 20 + Asciidoctor + Antora + all necessary packages;
** Used in CI for PDF and site builds;
** Built from `docker/Dockerfile.universal`;
** All package versions are pinned for reproducible builds (gems and npm packages with exact versions).
* **Kroki Service**: registry.gitlab.com/vvvnik/ods-project/kroki:0.28.0:
** Separate container for diagram rendering;
** Connected as service in CI;
** Base image: yuzutech/kroki:0.28.0.

== Build Scripts

=== Universal Image Build

[source,bash]
----
# Build and push to registry (default)
./docker/build-images.sh [tag]

# Build only, don't push to registry
./docker/build-images.sh [tag] --no-push

# Examples
./docker/build-images.sh 2
./docker/build-images.sh 2 --no-push
----

=== Kroki Image Build

[source,bash]
----
# Build and push to registry (default)
./docker/build-kroki.sh [tag]

# Build only, don't push to registry
./docker/build-kroki.sh [tag] --no-push

# Examples
./docker/build-kroki.sh 0.29.0
./docker/build-kroki.sh 0.29.0 --no-push
----

== Local Development

=== Using Ready-made Images

[source,bash]
----
# PDF generation
docker-compose -f docker/docker-compose.yml run --rm pdf

# Documentation site build
docker-compose -f docker/docker-compose.yml run --rm site

# With specific component
docker-compose -f docker/docker-compose.yml run --rm pdf ruby tools/start.rb airport-service
----

[NOTE]
After Docker site build, Antora outputs message `Open file:///app/public/index.html`, 
but you need to open `public/index.html` in the local project directory (on the host), 
since the `/app` directory inside the container is mounted to the project root.

=== Kroki Configuration for docker-compose

When using `docker-compose -f docker/docker-compose.yml run --rm site`, you need to configure `kroki-server-url` in `antora-playbook.yml`:

[source,yaml]
----
# For docker-compose local development:
kroki-server-url: http://host.docker.internal:8000

# Before pushing to CI, change to:
# kroki-server-url: http://kroki:8000 # for CI
----

:warning-caption: Important

[NOTE]
Before pushing changes to CI, make sure `kroki-server-url: http://kroki:8000` is set in `antora-playbook.yml`, otherwise CI build won't be able to connect to Kroki service.

== Architecture

The project uses a **universal approach** with one main image:

* **ruby-node-antora:2** – main image for all build operations;
* **kroki:0.28.0** – service for diagrams (PlantUML, Mermaid, Graphviz);

This provides:

* Fast builds (one image instead of two);
* Reliability (all dependencies in one place);
* Easy maintenance (fewer images to manage);
