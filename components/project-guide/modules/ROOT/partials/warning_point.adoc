:warning-caption: Внимание!
[WARNING]
====
Скрипт `tools/start.rb` должен запускаться **перед каждой сборкой Antora сайта**, если:

* Изменились схемы баз данных;
* Обновились API спецификации;
* Добавились новые страницы компонентов;
* Изменились диаграммы (BPMN, Draw.io, PlantUML).

Без предварительного запуска `start.rb` сайт Antora будет содержать устаревшую информацию.
====
