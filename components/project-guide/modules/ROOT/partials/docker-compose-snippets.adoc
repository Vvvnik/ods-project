== Примеры docker-compose

Пример конфигурации для запуска дополнительных сервисов (Kroki и Postgres) локально:

[source,yaml]
----
services:
  kroki:
    image: registry.gitlab.com/vvvnik/ods-project/kroki:0.28.0
    ports: ['8000:8000']
  postgres:
    image: postgres:15
    environment:
      POSTGRES_PASSWORD: postgres
    ports: ['5432:5432']
----

:note-caption: Важно

[NOTE]
Этот пример предназначен для локального запуска Kroki и Postgres как отдельных сервисов. 
Основной `docker/docker-compose.yml` содержит сервисы `pdf` и `site` для сборки документации.
