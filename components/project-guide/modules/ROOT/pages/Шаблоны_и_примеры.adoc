= Шаблоны и примеры

Папка `templates/` содержит готовые шаблоны и примеры для быстрого старта работы с документацией в системе ODS. Все шаблоны можно копировать и адаптировать под конкретный проект.

== Структура папки templates/

[source,text]
----
templates/
├── diagrams/              # Шаблоны и примеры диаграмм
│   ├── puml/             # Примеры PlantUML диаграмм
│   └── drawio/           # Примеры Draw.io диаграмм
├── glossary/             # Шаблон глоссария
├── snippets/             # Сниппеты кода для редакторов
└── templates_doc/        # Шаблоны документов
    └── modules/          # Модули с шаблонами документов
        ├── ed/           # Эксплуатационная документация
        ├── oed/          # Опытная эксплуатация
        ├── ROOT/         # Основные шаблоны
        └── trd/          # Техническая документация
----

== Шаблоны диаграмм

Папка `templates/diagrams/` содержит примеры диаграмм в различных форматах, которые можно использовать как основу для создания собственных диаграмм.

=== PlantUML диаграммы (puml/)

В папке `templates/diagrams/puml/` находятся примеры диаграмм на языке PlantUML:

==== kts.puml — пример архитектуры комплекса технических средств

Пример диаграммы архитектуры комплекса технических средств (КТС), демонстрирующий:

* Структуру уровней системы (вычисления, хранения, сети, управления);
* Взаимосвязи между компонентами;
* Использование стилей и цветов для визуализации;
* Оформление согласно стандартам;

Использование:

[source,bash]
----
# Копирование примера в ваш проект
cp templates/diagrams/puml/kts.puml \
   components/my-project/modules/ROOT/partials/diagrams/kts.puml
----

Затем включите диаграмму в документ:

[source,adoc]
----
[plantuml, hardware-architecture]
----
\include::partials/diagrams/kts.puml[plantuml, hardware-architecture]
----
----

==== net.puml — пример схемы сетевого взаимодействия

Пример диаграммы сетевого взаимодействия, показывающий:

* Архитектуру сети с различными зонами (DMZ, внутренняя сеть, сеть управления);
* Компоненты безопасности (WAF, DDoS Protection, VPN Gateway);
* Потоки данных между компонентами;
* Использование облачных элементов для визуализации;

Использование аналогично `kts.puml`.

=== Draw.io диаграммы (drawio/)

В папке `templates/diagrams/drawio/` находятся примеры диаграмм в формате Draw.io.

==== Проект_диаграмма_классов.drawio — пример диаграммы классов

Пример диаграммы классов проекта, демонстрирующий:

* Структуру проекта ODS с компонентами и модулями;
* Взаимосвязи между элементами системы;
* Использование различных типов элементов (swimlane, компоненты, файлы);
* Организацию диаграммы на нескольких страницах;

Использование:

[source,bash]
----
# Копирование примера в ваш проект
cp templates/diagrams/drawio/Проект_диаграмма_классов.drawio \
   components/my-project/modules/ROOT/examples/drawio/class-diagram.drawio
----

После копирования диаграмма будет автоматически конвертирована в SVG при генерации документации (если настроен конвертер Draw.io в `config.yml`).

== Шаблон глоссария

Папка `templates/glossary/` содержит шаблон файла глоссария.

=== glossary.adoc

Шаблон глоссария с предопределенными атрибутами для терминов и определений.

Структура шаблона:

[source,adoc]
----
:glossary-title: Глоссарий
:glossary-name: Глоссарий
:name-term-1: Компонент
:name-term-2: Определение компонента
----

Использование:

[source,bash]
----
# Копирование шаблона
cp templates/glossary/glossary.adoc \
   components/my-project/modules/ROOT/pages/Глоссарий.adoc
----

Затем заполните шаблон своими терминами и определениями.

== Сниппеты для редакторов

Папка `templates/snippets/` содержит готовые сниппеты кода для редакторов (VS Code, Cursor и др.), которые ускоряют создание документов в формате AsciiDoc.

=== asciidoc.code-snippets

Сниппеты для быстрого создания стандартных блоков:

* `num-t` — блок таблицы с автоматической нумерацией;
* `num-i` — блок рисунка с автоматической нумерацией;
* `num-e` — блок формулы с автоматической нумерацией;
* И другие полезные сниппеты;

Установка:

1. Скопируйте файл в папку `.vscode/` вашего проекта или в глобальную папку сниппетов редактора
2. Перезапустите редактор
3. Используйте префиксы сниппетов при наборе текста

Пример использования:

Введите `num-t` и нажмите Tab — появится готовый блок таблицы с нумерацией.

=== asciidoc-table.code-snippets

Специализированные сниппеты для создания таблиц:

* `table` — готовый блок таблицы с описанием данных;

Использование аналогично `asciidoc.code-snippets`.

== Шаблоны документов

Папка `templates/templates_doc/modules/` содержит полные шаблоны документов, организованные по типам документации.

=== Модуль ROOT

Основные шаблоны и примеры:

* `pages/index.adoc` — пример главной страницы компонента;
* `partials/` — общие части документов:
** `attr_common.adoc` — общие атрибуты
** `diagrams/` — примеры диаграмм
** `docs-db/` — примеры документации БД
** `lists/` — шаблоны списков
** `t_*.adoc` — шаблоны титульных страниц и подписей
* `examples/` — примеры конфигурационных файлов:
** `database.yml` — пример конфигурации БД
** `sources.yml` — пример конфигурации API
** `drawio/` — примеры Draw.io диаграмм
* `attachments/` — примеры PDF файлов;

=== Модуль TRD (Техническая документация)

Шаблоны документов технического задания:

* `pages/Частное_техническое_задание.adoc` — шаблон частного технического задания;
* `pages/Описание_постановки_задачи.adoc` — шаблон описания постановки задачи;
* `pages/Описание_автоматизируемых_функции.adoc` — шаблон описания функций;
* `pages/Спецификация.adoc` — шаблон спецификации;
* `partials/tables/specification-table.adoc` — шаблон таблицы спецификации;

Использование:

[source,bash]
----
# Копирование шаблона технического задания
cp templates/templates_doc/modules/trd/pages/Частное_техническое_задание.adoc \
   components/my-project/modules/trd/pages/Частное_техническое_задание.adoc
----

=== Модуль ED (Эксплуатационная документация)

Шаблоны эксплуатационной документации:

* `pages/Описание_программы.adoc` — шаблон описания программы;
* `pages/Описание_языка.adoc` — шаблон описания языка;
* `pages/Спецификация.adoc` — шаблон спецификации;
* `pages/Ведомость_эксплуатационных_документов.adoc` — шаблон ведомости;
* `partials/tables/` — шаблоны таблиц для спецификаций и ведомостей;

=== Модуль OED (Опытная эксплуатация)

Шаблоны документов опытной эксплуатации:

* `pages/Акт_приемки_в_опытную_эксплуатацию.adoc` — шаблон акта приемки;
* `pages/Протокол_опытнои_эксплуатации.adoc` — шаблон протокола;

== Рекомендации по использованию

=== Копирование шаблонов

1. Определите, какой тип документа вам нужен
2. Найдите соответствующий шаблон в `templates/templates_doc/modules/`
3. Скопируйте файл в ваш компонент
4. Адаптируйте содержимое под ваш проект

=== Адаптация шаблонов

После копирования шаблона:

1. Обновите атрибуты документа (название, версия, дата)
2. Замените примеры на реальные данные
3. Проверьте пути к include файлам
4. Обновите навигацию (`nav.adoc`)

=== Использование примеров диаграмм

Примеры диаграмм (`kts.puml`, `net.puml`, `Проект_диаграмма_классов.drawio`) можно:

1. Использовать как основу для создания собственных диаграмм
2. Изучать для понимания синтаксиса и стилей
3. Адаптировать под архитектуру вашего проекта
