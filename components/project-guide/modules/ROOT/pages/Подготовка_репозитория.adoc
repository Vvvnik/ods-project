= Подготовка репозитория

== Структура репозитория

[cols="1,2,3", options="header, breakable"]
|===
^|Папка ^|Назначение ^|Описание

|components/
|Компоненты Antora
|Содержит все компоненты документации (airport-service, data-processing-engine, information-system, toys-service, project-guide)

|tools/
|Инструменты сборки
|Скрипты и конфигурации для автоматизации

|resources/
|Ресурсы оформления
|Темы, шрифты для PDF

|docker/
|Docker конфигурация
|Dockerfile, docker-compose, скрипты сборки образов

|templates/
|Шаблоны и примеры
|Шаблоны документов, диаграммы, глоссарий

|ui-files/
|Пользовательский интерфейс
|UI компоненты для Antora (темы, стили, скрипты)

|public/
|Готовый сайт
|Сгенерированный статический сайт

== Корневые документы репозитория

В корне проекта находятся важные документы, описывающие проект и правила работы с ним:

[cols="1,2,3", options="header, breakable"]
|===
^|Файл ^|Назначение ^|Описание

|README.md
|Главный файл проекта
|Описание ODS, быстрый старт, ссылки на лицензии

|readme.adoc
|Альтернативный README
|Описание проекта в формате AsciiDoc

|MANIFESTO.adoc
|Манифест проекта
|Принципы, области применения, экосистема профилей ODS

|NOTICE.adoc
|Уведомление о стороннем ПО
|Список используемых библиотек и их лицензий

|LICENSE.md
|Сводная лицензия
|Объяснение двойной лицензионной модели проекта

|LICENSE-CODE.md
|Лицензия кода
|Apache 2.0 для кода, скриптов, инструментов

|LICENSE-DOCS.md
|Лицензия документации
|CC-BY 4.0 для документации, шаблонов, текстов

|package.json
|Node.js зависимости
|Описание зависимостей и скриптов

|package-lock.json
|Точные версии зависимостей
|Воспроизводимые сборки

|antora-playbook.yml
|Конфигурация Antora
|Настройки сборки сайта документации

|CONTRIBUTING.md
|Руководство по участию
|Правила участия, структура проекта, работа с документацией

|CODE_OF_CONDUCT.md
|Кодекс поведения
|Стандарты поведения участников проекта

|SUPPORT.md
|Поддержка проекта
|Где искать помощь, FAQ, контакты

|SECURITY.md
|Политика безопасности
|Процедуры сообщения об уязвимостях

|CHANGELOG.md
|История изменений
|Журнал изменений по стандарту Keep a Changelog
|===

Подробное описание всех корневых документов см. в xref:Корневые_документы_проекта.adoc[Корневых документах проекта].
