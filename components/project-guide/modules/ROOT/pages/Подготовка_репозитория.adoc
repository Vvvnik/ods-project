== Корневые документы репозитория

В корне проекта находятся важные документы, описывающие проект и правила работы с ним:

[cols="1,2,3"]
|===
|Файл |Назначение |Описание

|README.md
|Главный файл проекта
|Описание ODS, быстрый старт, ссылки на лицензии

|MANIFESTO.adoc
|Манифест проекта
|Принципы, области применения, экосистема профилей ODS

|LICENSE.md
|Сводная лицензия
|Объяснение двойной лицензионной модели проекта

|LICENSE-CODE.md
|Лицензия кода
|Apache 2.0 для кода, скриптов, инструментов

|LICENSE-DOCS.md
|Лицензия документации
|CC-BY 4.0 для документации, шаблонов, текстов

|CONTRIBUTING.md
|Руководство по участию
|Правила участия, структура проекта, работа с документацией

|CODE_OF_CONDUCT.md
|Кодекс поведения
|Стандарты поведения участников проекта

|SUPPORT.md
|Поддержка проекта
|Где искать помощь, FAQ, контакты

|SECURITY.md
|Политика безопасности
|Процедуры сообщения об уязвимостях

|CHANGELOG.md
|История изменений
|Журнал изменений по стандарту Keep a Changelog
|===

Подробное описание всех корневых документов см. в xref:Корневые_документы_проекта.adoc[Корневых документах проекта].
