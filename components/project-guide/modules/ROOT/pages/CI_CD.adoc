= CI/CD

== Этапы сборки

.Схема сборки
[plantuml, schema]
----
include::../examples/schema.puml[plantuml, schema]
----

[cols="1,2,3"]
|===
|Этап |Действие |Результат

|build_all
|Сборка PDF документов и генерация сайта
|Папка public/ с готовым сайтом

|pages
|Публикация на GitLab Pages
|Онлайн сайт документации

|prepare_release_notes
|Подготовка release notes по тегу
|Файл release-notes.adoc

|release
|Создание GitLab Release
|Официальный релиз с заметками
|===

== Зависимости

* pages зависит от build_all;
* prepare_release_notes выполняется только при создании тега;
* release зависит от prepare_release_notes.

== Отслеживание изменений

Добавьте в changes:

* tools/ - скрипты генерации и конфигурация;
* components/*/modules/ - содержимое документации;
* antora-playbook.yml - настройки сборки сайта;
* resources/ - темы и шрифты для PDF.
