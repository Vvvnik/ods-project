= Корневые документы проекта

В корне проекта ODS находятся важные документы, которые описывают проект, его лицензии, правила участия и поддержку.

== Основные документы

=== README.md
Главный файл проекта, содержащий:

* Описание ODS (Open Documentation Standard);
* Быстрый старт с командами установки и запуска;
* Информацию о лицензиях;
* Ссылки на основные ресурсы.

=== MANIFESTO.adoc
Манифест проекта, включающий:

* Принципы и цели ODS;
* Области применения стандарта;
* Экосистема профилей (ODS-API, ODS-DB, ODS-UML и др.);
* Таблица лицензий всех компонентов.

== Лицензии

Проект использует двойную лицензионную модель:

=== LICENSE.md
Сводный файл с объяснением лицензионной политики проекта.

=== LICENSE-CODE.md
Apache License 2.0 для:

* Кода и скриптов;
* Парсеров и конвертеров;
* CI/CD конфигураций;
* Инструментов генерации.

=== LICENSE-DOCS.md
Creative Commons Attribution 4.0 International (CC-BY 4.0) для:

* Документации, шаблонов и демо-данных;
* ГОСТ-подобных форм;
* Примеров AsciiDoc;
* Текстовых материалов.

== Участие в проекте

=== CONTRIBUTING.md
Подробное руководство по участию, включающее:

* Способы помощи проекту;
* Правила оформления Pull Requests;
* Структуру проекта и компонентов;
* Работу с документацией (AsciiDoc, Antora);
* Локальную разработку;
* Кодекс поведения.

=== CODE_OF_CONDUCT.md
Кодекс поведения участников проекта, основанный на Contributor Covenant:

* Обязательства участников;
* Стандарты приемлемого поведения;
* Процедуры разрешения конфликтов.

== Поддержка и безопасность

=== SUPPORT.md
Информация о поддержке проекта:

* Где искать помощь (Issues, чат сообщества);
* Часто задаваемые вопросы;
* Контактная информация.

=== SECURITY.md
Политика безопасности:

* Процедуры сообщения об уязвимостях;
* Поддерживаемые версии;
* Контактная информация для security issues.

== История изменений

=== CHANGELOG.md
Журнал изменений проекта, следующий стандарту Keep a Changelog:

* Формат основан на SemVer;
* Задокументированы все заметные изменения;
* Включает информацию о добавленных функциях, исправлениях и изменениях.

== Связи между документами

Все документы связаны между собой через перекрестные ссылки:

* README ссылается на лицензии и основные документы;
* CONTRIBUTING ссылается на CODE_OF_CONDUCT и SECURITY;
* SUPPORT ссылается на CONTRIBUTING и CHANGELOG;
* SECURITY ссылается на Issues для сообщений об уязвимостях.

== Рекомендации по использованию

* Начните с README.md для общего понимания проекта;
* Изучите MANIFESTO.adoc для понимания философии ODS;
* Ознакомьтесь с CONTRIBUTING.md перед началом участия;
* Используйте SUPPORT.md при возникновении вопросов;
* Следуйте SECURITY.md при обнаружении уязвимостей.

== Уведомление о демо-данных

Демо-данные, включенные в проект (например, API игрушек и схемы базы данных), предоставляются исключительно для целей документации и демонстрации. Эти демо-данные:

* Являются вымышленными и созданы только для примеров;
* Не представляют реальные продукты, услуги или бизнес-данные;
* Предназначены для демонстрации возможностей ODS;
* Не должны использоваться в продакшене.
