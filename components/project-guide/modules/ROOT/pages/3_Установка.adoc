== Docker (рекомендуемый способ)

Проект предоставляет готовый Docker образ со всеми необходимыми зависимостями:

[source,bash]
----
# Использование готового образа
docker pull registry.gitlab.com/vvvnik/ods-project/ruby-node-antora:2

# Генерация PDF
docker-compose -f docker/docker-compose.yml run --rm start

# Сборка сайта документации
docker-compose -f docker/docker-compose.yml run --rm site

# Сборка и предпросмотр сайта (порт 8080)
docker-compose -f docker/docker-compose.yml up site-preview
----

=== Как устроена локальная сборка через docker-compose

Для локальной сборки в `docker/docker-compose.yml` достаточно **двух сервисов**:

* **`pdf`** – генерация PDF;
* **`site`** – сборка сайта Antora.

Все внешние сервисы запускаются **на хосте** и доступны контейнерам через `host.docker.internal`:

* **Kroki** – `host.docker.internal:8000` (см. `antora-playbook.yml`);
* **Ollama** – `host.docker.internal:11434` (см. `docker-compose.yml` / `OLLAMA_HOST`);
* **PostgreSQL (pg-demo)** – `host.docker.internal` (см. `docker-compose.yml` / `DB_HOST`).

Проверка, что сервисы на хосте доступны:

[source,bash]
----
# Kroki: проверка реальным рендером PlantUML (GET / может отдавать 404 – это нормально)
printf '%s\n' '@startuml' 'Alice -> Bob: test' '@enduml' | \
  curl -sS -X POST http://localhost:8000/plantuml/svg \
    -H 'Content-Type: text/plain' \
    --data-binary @- -o /dev/null -w 'HTTP=%{http_code} CT=%{content_type}\n'
# Ожидаемый ответ:
# HTTP=200 CT=image/svg+xml

# Ollama (опционально): проверяйте только если используете LLM
curl -sS http://localhost:11434/api/version || true
# Ожидаемый ответ (пример):
# {"version":"0.13.4"}

# PostgreSQL: psql может быть не установлен – проверим, что порт доступен
nc -vz localhost 5432
# Ожидаемый ответ (пример):
# Connection to localhost port 5432 [tcp/postgresql] succeeded!
----

=== Содержимое Docker образа

* **Ruby 3.2** + gems: `asciidoctor`, `asciidoctor-pdf`, `asciidoctor-diagram`, `asciidoctor-kroki`, `prawn`, `pg`, `hexapdf`;
* **Node.js 20** + глобальные npm-пакеты из `docker/Dockerfile.universal` (версии зафиксированы): `@antora/cli`, `@antora/site-generator-default`, `@antora/site-generator`, `@antora/lunr-extension`, `@opendevise/antora-swagger-ui-extension`, `puppeteer`, `xml2js`;
* Набор согласован с секцией `antora.extensions` в `antora-playbook.yml` (Swagger UI для OpenAPI и Lunr для поиска en/ru).
* **Системные зависимости**: build-essential, git, curl, fonts;

== Локальная установка

=== Требования к версиям

* **Ruby**: 3.2 или выше;
* **Node.js**: 20 или выше (LTS рекомендуется);
* **Git**: любая актуальная версия;

=== Системные зависимости

Для компиляции Ruby gems требуются:

* **Linux**: `build-essential`, `libpq-dev` (для gem `pg`);
* **macOS**: Xcode Command Line Tools (`xcode-select --install`);
* **Windows**: Ruby DevKit или MSYS2;

=== Установка Ruby gems

Полный список необходимых gems:

[source,bash]
----
gem install asciidoctor asciidoctor-pdf asciidoctor-diagram asciidoctor-kroki rouge prawn hexapdf pg graphviz
----

Описание gems:

* `asciidoctor` – процессор AsciiDoc;
* `asciidoctor-pdf` – генерация PDF документов;
* `asciidoctor-diagram` – поддержка диаграмм;
* `asciidoctor-kroki` – интеграция с Kroki;
* `rouge` – подсветка синтаксиса;
* `prawn` – библиотека для PDF;
* `hexapdf` – работа с PDF файлами;
* `pg` – драйвер PostgreSQL;
* `graphviz` – генерация ERD диаграмм;

:note-caption: Важно

[NOTE]
`graphviz` gem нужен только для локальной генерации БД документации. 
В Docker образе его нет, так как генерация БД отключена в CI.
Если планируется включить генерацию БД в CI, необходимо добавить `graphviz` в `docker/Dockerfile.universal`.

=== Установка Node.js пакетов

[source,bash]
----
npm install
----

Это установит все зависимости из `package.json`:

* `@antora/cli` – CLI для Antora;
* `@antora/lunr-extension` – поиск по документации (в playbook подключён с языками en и ru);
* `@opendevise/antora-swagger-ui-extension` – встраивание Swagger UI для OpenAPI на сайте Antora (в `package.json` может отсутствовать; для локального `npx antora` установите пакет или ориентируйтесь на глобальную установку из Docker-образа);
* `asciidoctor-kroki` – интеграция Kroki;
* `asciidoctor-plantuml` – поддержка PlantUML;
* `puppeteer` – для генерации BPMN диаграмм;
* `xml2js` – парсинг Draw.io файлов;
* `opal` – выполнение Ruby кода;

----

=== Установка Ollama (опционально)

Для работы с LLM переводами требуется Ollama. Подробнее см. xref:Работа_с_LLM.adoc[Работа с LLM].

----
# Установка Ollama

ollama pull gemma:latest
----

=== Проверка установки

После установки всех зависимостей проверьте, что все работает:

[source,bash]
----
# Проверка версий
ruby -v          # Должно быть 3.2 или выше
node -v          # Должно быть 20 или выше
npm -v           # Должна быть актуальная версия
git --version    # Любая актуальная версия

# Проверка Ruby gems
gem list | grep asciidoctor    # Должны быть установлены все gems
gem list | grep prawn
gem list | grep hexapdf
gem list | grep pg

# Проверка Node.js пакетов
npm list --depth=0              # Должны быть установлены все пакеты

# Проверка системных инструментов
graphviz --version              # Для ERD диаграмм
java -version                   # Для PlantUML (если установлен)
docker --version                # Для Docker
postgresql --version            # Для БД (если установлен)

# Проверка Asciidoctor
asciidoctor -v
asciidoctor-pdf -v

# Проверка Antora
antora -v                       # Или npx antora --version
----

Если все команды выполняются без ошибок, установка прошла успешно.
