== Docker (рекомендуемый способ)

Проект предоставляет готовый Docker образ со всеми необходимыми зависимостями:

[source,bash]
----
# Использование готового образа
docker pull registry.gitlab.com/vvvnik/my-project/ruby-node-antora:1

# Генерация PDF
docker-compose -f docker/docker-compose.yml run --rm pdf

# Сборка сайта документации
docker-compose -f docker/docker-compose.yml run --rm site
----

=== Содержимое Docker образа

* **Ruby 3.2** + gems: `asciidoctor`, `asciidoctor-pdf`, `asciidoctor-diagram`, `asciidoctor-kroki`, `prawn`, `pg`, `hexapdf`
* **Node.js 20** + пакеты: `@antora/cli`, `@antora/site-generator`, `@antora/lunr-extension`, `puppeteer`, `xml2js`
* **Системные зависимости**: build-essential, git, curl, fonts

== Локальная установка

=== Windows

* Установите Git, Node.js (LTS), Ruby, Graphviz;
* Установите Java (для PlantUML при необходимости);
* Установите Docker Desktop;
* Ruby gems: gem install asciidoctor asciidoctor-pdf asciidoctor-kroki;
* Node: npm install.

=== Linux

* Установите Git, Node.js (LTS), Ruby, Graphviz;
* Установите Docker Engine и Docker Compose;
* Ruby gems: gem install asciidoctor asciidoctor-pdf asciidoctor-kroki;
* Node: npm install.

=== macOS

* Установите Homebrew;
* brew install node ruby graphviz;
* Установите Docker Desktop;
* Ruby gems: gem install asciidoctor asciidoctor-pdf asciidoctor-kroki;
* Node: npm install.
