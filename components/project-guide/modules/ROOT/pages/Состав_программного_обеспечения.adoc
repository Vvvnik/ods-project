= Состав программного обеспечения

Документ описывает структуру проекта ODS и назначение всех папок и файлов.

== Корневая структура проекта

. `components/` - папка с компонентами документации;
. `tools/` - инструменты и скрипты для генерации;
. `resources/` - ресурсы (темы, шрифты);
. `.gitlab-ci.yml` - конфигурация CI/CD;
. `antora-playbook.yml` - конфигурация Antora;
. `.gitignore` - исключения для Git;

== Папка components/

Содержит все компоненты документации проекта.

=== Структура компонента

Каждый компонент имеет следующую структуру:

. `modules/` - модули документации;
.. `ROOT/` - основной модуль;
... `pages/` - страницы документации (.adoc файлы);
... `partials/` - частичные файлы;
.... `lists/` - автоматически генерируемые списки;
.... `docs-api/` - документация API (если включена);
.... `docs-db/` - документация БД (если включена);
... `attachments/` - вложения (PDF файлы);
... `images/` - изображения;
.... `bpmn/` - BPMN диаграммы (если включены);
.... `drawio/` - Draw.io диаграммы (если включены);
.... `images-db/` - схемы БД (если включены);
... `examples/` - исходные файлы;
.... `bpmn/` - исходники BPMN диаграмм;
.... `drawio/` - исходники Draw.io диаграмм;
.... `sources.yml` - источники API;
.... `database.yml` - профили БД;
.. `ed/`, `trd/`, `oed/` - дополнительные модули;

=== Компоненты проекта

. `airport-service` - сервис аэропорта;
. `data-processing-engine` - движок обработки данных;
. `information-system` - информационная система;
. `toys-service` - сервис игрушек;
. `project-guide` - руководство по проекту;

== Папка tools/

Содержит все инструменты для генерации документации.

=== Скрипты генерации

. `start.rb` - основной скрипт запуска генерации;
. `scripts/` - папка со скриптами;
.. `convert_ascii_to_pdf.rb` - универсальный конвертер PDF (активный);
.. `bpmn_to_img.js` - конвертер BPMN в изображения;
.. `drawio_to_img.js` - конвертер Draw.io в изображения;
.. `db_to_adoc.rb` - конвертер БД в AsciiDoc;
.. `openapi-swagger-adoc.rb` - конвертер OpenAPI в AsciiDoc;
.. `generate_lists.rb` - генератор списков файлов;
.. `create_cover_sheet.rb` - создание обложки;
.. `translations_one.rb` - переводы;
.. `viewer.html` - просмотрщик;

=== Библиотеки

. `lib/` - папка с библиотеками Ruby;
.. `list_generator.rb` - генератор списков файлов;
.. `pdf_generator.rb` - генератор PDF;
.. `approval_page_generator.rb` - генератор листов утверждения;
.. `config_loader.rb` - загрузчик конфигурации;
.. `config_parser.rb` - парсер конфигурации;
.. `title_page_blocks.rb` - блоки титульных страниц;
.. `ordinal_word_ru.rb` - порядковые числительные на русском;
.. `utils.rb` - вспомогательные функции;
.. `convert_title_page_original.rb` - конвертер титульной страницы (стандартная);
.. `convert_title_page_contract.rb` - конвертер титульной страницы (контракт);
.. `convert_title_page_original_frame.rb` - конвертер титульной страницы (с рамкой);
.. `convert_approval_page_gost.rb` - конвертер листа утверждения ГОСТ;
.. `convert_other_page_original.rb` - конвертер обычных страниц (стандартные);
.. `convert_other_page_original_frame.rb` - конвертер обычных страниц (с рамкой);
.. `convert_list_alphabetic.rb` - конвертер списков (alphabetic);
.. `convert_list_dash.rb` - конвертер списков (dash);

=== Конфигурация

. `config.yml` - основная конфигурация проекта;
. `config_type_page.yml` - конфигурация типов страниц и списков;

== Папка resources/

Содержит ресурсы для оформления документов.

=== Темы

. `themes/` - папка с темами PDF;
.. `report-theme.yml` - основная тема отчетов;
.. `frame-theme.yml` - тема для документов с рамками;

=== Шрифты

. `fonts/` - папка со шрифтами (если используется);

== Файлы конфигурации

=== CI/CD

. `.gitlab-ci.yml` - конфигурация GitLab CI/CD;
.. Содержит этапы сборки PDF и сайта;
.. Настройки переменных окружения;
.. Правила запуска пайплайнов;

=== Antora

. `antora-playbook.yml` - конфигурация Antora;
.. Настройки сборки сайта документации;
.. Конфигурация Kroki сервера;
.. Атрибуты для Antora;

=== Git

. `.gitignore` - исключения для Git;
.. Игнорирует временные файлы;
.. Исключает сгенерированные изображения;
.. Сохраняет необходимые скрипты;

== Логика работы start.rb

=== Основные этапы

. Чтение конфигурации из `config.yml`;
. Обработка каждого компонента;
. Генерация диаграмм (BPMN, Draw.io);
. Генерация API документации;
. Генерация БД документации;
. Генерация PDF документов;
. Генерация списков файлов;

=== Условная логика

. Проверка переменной `ENV['CI']`;
.. В CI отключается генерация диаграмм;
.. В CI отключается генерация API;
.. В CI отключается генерация БД;
. Локально работает полная генерация;

== Конфигурация config.yml

=== Секция defaults

Содержит настройки по умолчанию для всех компонентов.

. `bpmn` - настройки BPMN диаграмм;
.. `enabled` - включить/отключить генерацию;
.. `src` - исходная папка;
.. `dst` - папка назначения;
.. `erase_destination_folder` - очистка папки;

. `drawio` - настройки Draw.io диаграмм;
.. `enabled` - включить/отключить генерацию;
.. `src` - исходная папка;
.. `dst` - папка назначения;
.. `erase_destination_folder` - очистка папки;

. `api` - настройки API документации;
.. `enabled` - включить/отключить генерацию;
.. `dst` - папка назначения;
.. `api_sources_file` - файл источников;
.. `erase_destination_folder` - очистка папки;

. `db` - настройки БД документации;
.. `enabled` - включить/отключить генерацию;
.. `images_dir` - папка изображений;
.. `dst` - папка назначения;
.. `database_connect_file` - файл подключения;
.. `profile` - профиль БД;

. `pdf` - настройки PDF генерации;
.. `enabled` - включить/отключить генерацию;
.. `src` - исходная папка;
.. `dst` - папка назначения;
.. `converter` - путь к конвертеру;
.. `theme` - тема оформления;
.. `use_title_pages` - титульные страницы;

. `list` - настройки генерации списков;
.. `enabled` - включить/отключить генерацию;
.. `adoc_lists` - списки .adoc файлов;
.. `pdf_lists` - списки PDF файлов;
.. `dst` - папка назначения;

=== Секция components

Содержит список компонентов с индивидуальными настройками.

. Каждый компонент наследует настройки из `defaults`;
. Можно переопределить любые параметры;
. Порядок секций не важен;

== Модульная архитектура конвертеров

=== Универсальный конвертер

. `convert_ascii_to_pdf.rb` - основной конвертер;
.. Загружает конфигурацию из `config_type_page.yml`;
.. Динамически подключает модули;
.. Выбирает тему PDF автоматически;

=== Модули титульных страниц

. `convert_title_page_original.rb` - стандартная титульная;
. `convert_title_page_contract.rb` - для контрактов;
. `convert_title_page_original_frame.rb` - с рамками;
. `convert_approval_page_gost.rb` - лист утверждения ГОСТ;

=== Модули обычных страниц

. `convert_other_page_original.rb` - с полными рамками;
. `convert_other_page_original_frame.rb` - с рамками и приставкой;

=== Модули списков

. `convert_list_alphabetic.rb` - стиль alphabetic;
. `convert_list_dash.rb` - стиль dash;

== Автоматическая генерация

=== Списки файлов

. Генерируются автоматически;
. Создаются в `modules/ROOT/partials/lists/`;
. Обновляются при каждой сборке;
. Содержат навигацию по документам;

=== PDF документы

. Генерируются из .adoc файлов;
. Сохраняются в `modules/ROOT/attachments/`;
. Используют настроенные темы;
. Поддерживают титульные страницы;

=== Диаграммы

. BPMN конвертируются в SVG через Puppeteer;
. Draw.io конвертируются в SVG через Desktop приложение;
. PlantUML обрабатываются через Kroki;
. Сохраняются в соответствующих папках images/;
