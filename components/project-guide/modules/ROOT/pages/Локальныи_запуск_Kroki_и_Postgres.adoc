= Локальный запуск Kroki и Postgres
:sectnums:

== Kroki

Kroki используется для рендеринга диаграмм (PlantUML, Mermaid, Graphviz) в проекте.

=== Запуск локально (Docker)

[source,bash]
----
docker run --rm -p 8000:8000 registry.gitlab.com/vvvnik/ods-project/kroki:0.28.0
----

=== Именованный контейнер и проброс порта (после сборки / pull)

Если образ собран локально (`./docker/build-kroki.sh --no-push`) или получен из реестра после CI, удобно запускать Kroki в фоне с фиксированным именем и **пробросом 8000:8000** (обязательно для `host.docker.internal:8000` из `docker-compose`):

[source,bash]
----
docker rm -f ods-kroki 2>/dev/null; docker run -d --name ods-kroki -p 8000:8000 registry.gitlab.com/vvvnik/ods-project/kroki:0.28.0
----

Подробности и связь с `build-kroki.sh`: xref:4_Docker_сборка_и_сервисы.adoc#kroki-local-port[Docker: сборка Kroki с пробросом порта].

=== Переменные окружения

В проекте используется переменная `KROKI_SERVER_URL` для указания адреса Kroki сервера:

* Локально: `http://localhost:8000`;
* В CI: `http://kroki:8000`;

=== Конфигурация Antora

В `antora-playbook.yml` расширение Kroki подключено, но `kroki-server-url` **не хардкодится** под конкретное окружение.
URL Kroki передаётся в Antora через CLI-атрибут `kroki-server-url`.

:warning-caption: Важно

[NOTE]
Для локального запуска Antora укажите URL Kroki через CLI-атрибут:

[source,bash]
----
npx antora generate --attribute kroki-server-url=http://localhost:8000 antora-playbook.yml
----

Это позволяет не менять `antora-playbook.yml` вручную при переключении между локальной разработкой и CI.

Альтернатива – использовать docker-compose сервис `site`, который уже передаёт `kroki-server-url` через `KROKI_SERVER_URL`:

[source,bash]
----
docker-compose -f docker/docker-compose.yml run --rm site
----

== Postgres

PostgreSQL используется как источник данных для генерации документации БД.

=== Запуск локально (Docker)

[source,bash]
----
docker run --rm -e POSTGRES_PASSWORD=postgres -p 5432:5432 postgres:15
----

=== Подключение к БД

После запуска PostgreSQL доступен по адресу:

* Хост: `localhost`;
* Порт: `5432`;
* Пользователь: `postgres`;
* Пароль: `postgres`;

== Docker Compose

Для удобства можно использовать docker-compose файл:

[source,yaml]
----
version: '3.8'
services:
  kroki:
    image: registry.gitlab.com/vvvnik/ods-project/kroki:0.28.0
    ports: ['8000:8000']
  postgres:
    image: postgres:15
    environment:
      POSTGRES_PASSWORD: postgres
    ports: ['5432:5432']
----

Запуск:
[source,bash]
----
docker-compose up -d
----

== Интеграция с проектом

Эти сервисы используются в:

* **CI/CD** - Kroki запускается как сервис в GitLab CI;
* **Локальная разработка** - для тестирования генерации диаграмм и БД документации;
* **Скрипт db_to_adoc.rb** - подключается к PostgreSQL для извлечения схемы БД;
* **Antora** - использует Kroki для рендеринга PlantUML диаграмм.
