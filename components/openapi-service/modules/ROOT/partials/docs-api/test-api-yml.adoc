Тип: integer

----


==== limit

Тип: integer

Описание: Количество пользователей на странице

Обязательность: Необязательный параметр

Расположение: query

Пример:

[source,json]

----


==== search

Тип: string

Описание: Поиск по имени или email пользователя

Обязательность: Необязательный параметр

Расположение: query

Пример:

[source,json]

Тип: string

Описание: Фильтр по статусу пользователя
