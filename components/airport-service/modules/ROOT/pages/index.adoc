== Назначение документа
Данный компонент демонстрирует возможности автоматической генерации документации из базы данных PostgreSQL.

Документ содержит описание сервиса аэропортов, включая схему базы данных, структуру таблиц и логические связи между сущностями системы управления аэропортами. 

=== О системе парсинга БД
Система поддерживает подключение к базам данных PostgreSQL и автоматически создает:

* ERD диаграммы (Entity Relationship Diagrams);
* Логические диаграммы базы данных;
* Подробное описание всех таблиц и их связей;
* Документацию по индексам и ограничениям.

=== Процесс генерации документации

Документация генерируется в несколько этапов:

==== Подключение к БД
Система подключается к PostgreSQL используя настройки из `database.yml`:

[source,yaml]
----
host: localhost
port: 5432
database: airport_db
username: postgres
password: password
----

==== Анализ схемы
Автоматически извлекается следующая информация:

* Таблицах и их структуре;
* Связях между таблицами (foreign keys);
* Индексах и ограничениях;
* Типах данных и размерах полей.

==== Генерация диаграмм
Создаются SVG диаграммы с помощью Graphviz:

* ERD диаграмма (физическая модель);
* Логическая диаграмма (концептуальная модель).

==== Создание документации
Генерируется AsciiDoc документация с следующей информацией:

* Описанием всех таблиц;
* Детализацией полей и их типов;
* Схемами связей между таблицами.

Пример документации xref:Схемы_данных.adoc[Схемы данных].

== Заключение

Данный компонент наглядно демонстрирует возможности автоматической генерации документации из базы данных:

* **Автоматический парсинг** – система автоматически извлекает структуру БД;
* **Генерация диаграмм** – создаются профессиональные ERD и логические диаграммы;
* **Документирование таблиц** – подробное описание всех полей и связей;
* **Поддержка любых БД** – система работает с PostgreSQL, MySQL, Oracle и другими;
* **Интеграция с CI/CD** – документация обновляется автоматически при изменениях в БД.

Система парсинга БД позволяет быстро создавать актуальную техническую документацию для любых проектов, экономя время разработчиков и обеспечивая высокое качество документации.
