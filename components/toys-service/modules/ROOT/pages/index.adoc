= Сервис игрушек

== Назначение документа

Документ демонстрирует возможности автоматической генерации API документации из различных источников:

* Парсинг OpenAPI спецификаций в YAML и JSON форматах;
* Обработка ссылок на Swagger UI документацию;
* Автоматическое создание AsciiDoc документации из API схем.

== Общее описание

=== Назначение демо-сервиса

Сервис игрушек служит демонстрационным примером для показа возможностей системы генерации документации ODS при работе с API.

Основные демонстрационные функции:

* Парсинг OpenAPI спецификаций из файлов YAML/JSON;
* Обработка внешних ссылок на Swagger документацию;
* Автоматическая генерация AsciiDoc из API схем;
* Создание интерактивной документации с примерами запросов.

=== Демонстрационная архитектура

Система демонстрирует парсинг RESTful API с использованием OpenAPI спецификации.

Демонстрационные компоненты:

* Пользователи - пример парсинга схемы пользователей;
* Товары - демонстрация обработки каталога товаров;
* Аутентификация - пример схемы авторизации.

== API Документация

=== Общие сведения

Демонстрационный сервис показывает возможности парсинга API с поддержкой:

* JSON и YAML форматов OpenAPI спецификаций;
* HTTPS и HTTP протоколов;
* Пагинации и фильтрации;
* Аутентификации через токены.

=== Основные эндпоинты

Основные эндпоинты:

* GET /users - получение списка пользователей;
* POST /users - создание нового пользователя;
* GET /products - получение каталога товаров;
* POST /products - добавление нового товара;
* POST /auth/login - аутентификация пользователя;

== Примеры использования

=== Получение списка товаров

[source,http]
----
GET /api/v1/products?page=1&limit=10&category=toys HTTP/1.1
Host: api.toys-service.com
Authorization: Bearer <token>
Content-Type: application/json
----

=== Создание нового пользователя

[source,http]
----
POST /api/v1/users HTTP/1.1
Host: api.toys-service.com
Content-Type: application/json

{
  "name": "Иван Иванов",
  "email": "ivan@example.com",
  "password": "secure_password"
}
----

=== Аутентификация

[source,http]
----
POST /api/v1/auth/login HTTP/1.1
Host: api.toys-service.com
Content-Type: application/json

{
  "email": "ivan@example.com",
  "password": "secure_password"
}
----

== Пример описания такого сервиса

=== Источники данных

Демонстрационный сервис использует следующие источники для генерации документации:

* examples/api/toys-api.yaml - OpenAPI спецификация в YAML формате;
* examples/api/toys-api.json - OpenAPI спецификация в JSON формате;
* examples/sources.yml - конфигурация источников API.

=== Процесс генерации

Система ODS автоматически:

* Парсит OpenAPI спецификации из YAML и JSON файлов;
* Обрабатывает ссылки на внешние Swagger UI ресурсы;
* Генерирует AsciiDoc документацию с примерами запросов;
* Создает интерактивные схемы данных;
* Формирует навигацию по API эндпоинтам.

=== Результат

В результате получается полноценная документация API, включающая:

* Описание всех эндпоинтов;
* Схемы данных и модели;
* Примеры запросов и ответов;
* Интерактивные элементы для тестирования.

== Заключение

Демонстрационный сервис игрушек показывает возможности системы ODS по автоматической генерации API документации из различных источников. Пример демонстрирует парсинг OpenAPI спецификаций, создание интерактивной документации и интеграцию с внешними Swagger ресурсами.
