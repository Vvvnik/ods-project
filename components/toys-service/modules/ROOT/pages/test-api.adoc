== Общие сведения

Наименование:  Тестовый API сервиса игрушек.

Версия OpenAPI: 2.0.

Версия API: 1.0.0.

Описание: Полнофункциональный тестовый API для сервиса игрушек. Включает все типы параметров, схемы данных, коды ответов и примеры для тестирования интеграции с системой управления игрушками.

=== GET «/users»

*Описание:* Получить список пользователей

*Детальное описание:* Возвращает список всех пользователей с возможностью фильтрации и пагинации

"tags": «Пользователи».

|search |string |- |Поиск по имени или email пользователя
|status |string |- |Фильтр по статусу пользователя

==== Детальное описание параметров

===== page

*Тип:* integer

*Описание:* Номер страницы для пагинации

*Обязательность:* Необязательный параметр

*Расположение:* query

*Пример:* `1`


===== limit

*Тип:* integer

*Описание:* Количество пользователей на странице

*Обязательность:* Необязательный параметр

*Расположение:* query

*Пример:* `20`


===== search

*Тип:* string

*Описание:* Поиск по имени или email пользователя

*Обязательность:* Необязательный параметр

*Расположение:* query

*Пример:* `john`


===== status

*Тип:* string

*Описание:* Фильтр по статусу пользователя

*Обязательность:* Необязательный параметр

*Расположение:* query

*Пример:* `active`


==== Ответы сервера

Возможные ответы сервера:

* «200» Список пользователей успешно получен;
* «400» Некорректные параметры запроса;
* «401» Требуется аутентификация;
* «500» Внутренняя ошибка сервера;
