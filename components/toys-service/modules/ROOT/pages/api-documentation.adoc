= Документация API сервиса игрушек



== Общие сведения

Наименование:  Сервис игрушек.

Версия OpenAPI: 2.0.

Версия API: 1.0.0.

Описание: Сервис игрушек предоставляет RESTful API для управления каталогом игрушек, пользователями системы и процессами аутентификации. API поддерживает все основные операции CRUD для товаров и пользователей.
