# 💼 COMMERCIAL OPTIONS

## Overview

**ODS (Open Documentation Standard)** — это открытый проект, распространяемый под лицензиями Apache 2.0 и CC-BY 4.0.  
Базовые функции, структура стандартов и инструменты сборки доступны свободно.  

Для организаций и профессиональных пользователей доступны дополнительные коммерческие возможности и сервисы поддержки.

---

## 🔧 Premium Features

- 🎨 **ODS Premium Templates** — расширенные темы оформления PDF и AsciiDoc (ГОСТ-подобные, корпоративные, брендированные).  
- 🧠 **AI-Assisted Review** — проверка грамматики, терминов и стиля текста в `.adoc` файлах.  
- ☁️ **ODS Cloud Builder** — облачная сборка и публикация документации без локальной установки.  
- 🧩 **Integration Plugins** — коннекторы для Confluence, GitLab CI, Jira, и других систем.
