= Манифест ODS (Open Documentation Standard)

*(Не связан с форматом OpenDocument Spreadsheet (.ods) или инициативами Open Data)*  

**ODS (Open Documentation Standard)** — это открытый стандарт для организации и автоматизации технической документации в ИТ-проектах.

Наша цель — сделать документацию воспроизводимой, модульной и пригодной как для открытых, так и для корпоративных решений.

== Принципы

* 📂 Документация как код (*Docs as Code*).
* 🖨 Автоматическая генерация HTML и PDF.
* 🔄 Воспроизводимость в CI/CD.
* 🌍 Открытость и совместимость.
* 🧾 ГОСТ-подобные формы при необходимости.

== Области применения
ODS применяется в:

* документировании микросервисов,
* описании API (OpenAPI, AsyncAPI, GraphQL),
* проектировании и описании БД (ERD, DDL),
* моделировании процессов (BPMN, UML, PlantUML),
* подготовке ГОСТ-документации (ТЗ, Описание программы, Руководства).

== Экосистема
ODS состоит из профилей:

* ODS-API — для API.
* ODS-DB — для БД.
* ODS-UML — для UML/моделирования.
* ODS-BPMN — для бизнес-процессов.
* ODS-GOST — для ГОСТ-доков.
* ODS-OPS — для эксплуатационной документации.

== Прозрачность лицензий
[options="header", cols="3,2,5"]
|===
| Компонент  | Лицензия | Применение в ODS
| ODS (код, скрипты) | Apache-2.0 | Собственные парсеры, конвертеры, CI/CD, генерация.
| ODS (шаблоны, тексты) | CC-BY 4.0 | ГОСТ-подобные формы, примеры AsciiDoc.
| Antora | MPL-2.0 | Генерация сайта документации (используется как зависимость).
| Asciidoctor | MIT | Конвертация AsciiDoc в HTML/PDF.
| Asciidoctor PDF | MIT | Сборка PDF с кастомными конвертерами.
| draw.io / diagrams.net | Apache-2.0 | Редактор диаграмм (ERD, блок-схемы и т.д.).
| Kroki | MIT | Рендеринг UML/PlantUML/Mermaid/Graphviz диаграмм.
| PlantUML (движок) | GPL v3 | Используется через Kroki/CLI. Сгенерированные диаграммы (SVG/PNG) **не GPL** и свободны к использованию.
| OpenAPI / AsyncAPI спецификации | Apache-2.0 | JSON/YAML спецификации API.
| GraphQL SDL | Open Standard | Схемы GraphQL для API.
| SQL/ERD схемы БД | Open Standard | Используются для генерации описаний таблиц.
| Демо-данные (API игрушек, схемы БД) | CC-BY 4.0 | Используются только как примеры документации, не для продакшена.
|===

ODS развивается как открытый стандарт с возможностью коммерческой поддержки, внедрения и дополнительных расширений (по отдельному договору), не ограничивающих лицензии Apache-2.0 и CC-BY 4.0.

== Заключение
ODS — это шаг к созданию воспроизводимого и проверяемого стандарта технической документации для современных ИТ-систем.

Мы приглашаем сообщество использовать, тестировать и предлагать улучшения.
